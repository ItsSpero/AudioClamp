# AudioClamp v2.6.2

A visual polish and interface decluttering release.

### What's New
* **Midnight Navy Theme**: Unified dark blue aesthetic with calm Ice Blue accents, eliminating harsh neon colors and visual glare.
* **Decluttered Interface**: Removed 12 inline `(?)` bubbles, streamlined sliders, and condensed game presets into a sleek horizontal strip.
* **Clean Titlebar**: Standalone playback device quick-switcher and compact latency badge.
* **Under the Hood**: Purged legacy fallback code, dead HTML elements, and duplicate CSS for lighter, cleaner rendering.
